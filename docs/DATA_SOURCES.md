# Solar resource, standards and site-data references

These sources can support preliminary site assessment. They do not replace local measurements, equipment datasheets or engineering review.

| Source | Potential use | Notes |
|---|---|---|
| [Global Solar Atlas / World Bank Bangladesh solar irradiation and PV potential dataset](https://datacatalog.worldbank.org/search/dataset/0039840/bangladesh-solar-irradiation-and-pv-power-potential-map) | Regional solar-resource screening and comparative site assessment | Record location, variable, resolution, dataset version and download date |
| [NASA POWER daily API documentation](https://power.larc.nasa.gov/docs/services/api/temporal/daily/) | Daily solar and meteorological time series | Review the variable definitions, temporal aggregation and spatial grid limitations |
| [SREDA solar component standards for the net-metering programme](https://sreda.portal.gov.bd/pages/static-pages/6922db99933eb65569e0b2bc) | Bangladesh component standards and certification context | Check the current applicable standard list and system type |
| [Bangladesh Net Metering Guideline 2025](https://nem.powerdivision.gov.bd/Faq) | Grid-connected/net-metered system context | A standalone off-grid design may fall outside its scope, but applicable electrical safety requirements still matter |
| [Power Division policy portal](https://powerdivision.gov.bd/pages/static-pages/694032be35ce18e1c0561a07) | Current energy-policy context | Policy information is not a substitute for site engineering data |

## Site data to collect

- coordinates, elevation, horizon and nearby shading;
- monthly irradiation on the relevant plane, ambient temperature and module temperature;
- measured load data across weekdays, weekends and seasons;
- appliance start/surge information and critical-load classification;
- module, inverter, controller, battery and protection-device datasheets;
- cable routes, installation method, ambient conditions and earthing arrangement.

Record data source, access date, resolution, unit, processing and assumptions. Never combine PSH estimates, measured kWh/m²/day and AC output without stating their conversion.
